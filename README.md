# TravelPlaner – 산악 여행지 후보 비교 가이드

캐나다 밴프 & 재스퍼, 뉴질랜드 남섬, 이탈리아 돌로미티 3곳의 명소 사진, 장단점, 유의사항, 팁을 출처와 함께 비교하는 웹페이지입니다.

- `index.html`: 사이트 본체. HTML 파일 하나이고 빌드 과정이 없어서 브라우저로 바로 열 수 있습니다.
- `plan.md` / `done.md` / `data-notes.md`: 계획서, 완료 체크리스트, 데이터 출처 메모
- `tests/`: `node --test tests/`로 실행합니다 (Node 18 이상, 브라우저 테스트에는 Chrome 필요).

> 요금·예약 규정·입국 요건은 자주 바뀝니다. 출발 전에 공식 사이트에서 다시 확인하세요.
